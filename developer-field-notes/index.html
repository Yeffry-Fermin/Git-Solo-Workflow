What is Git

Git is a tool for version control. It allows you to keep a log of your code history and revert to a previous version of the codebase. One of the most powerful features is how seamless it is at allowing collaboration of multiple developers in a single codebase.

What is Github

Github is a repository hub where you can store your codebase and see your version control history changes in a more intuituve and user friendly way

Git status

Showes you exactly which files have been modified, which ones are ready to be saved, and which ones Git isn't tracking yet.

Git commit

takes a permanent snapshot of your staged changes, creating a secure save point in your project's history that you can always look back on or roll back to if something breaks.

Git push

Pushes yours staged code into that specified branch

Git branch

Creates a branch of your current project so you can safely work on code that wont affect the main codebase

Git pull

Fetches the latest changes from your remote repository to reflect them in your local file

Git init

Initializes your project with a empty git repository in your working folder

Git log

Gives you a list of your current commit history chronologically

Git clone

This command copies an exisisting repository from a site like github and downloads it to your local pc
